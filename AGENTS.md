# AstroRoute coding instructions

- Import only modules and names that are used by the file.
- Prefer readable multi-line code over compressed one-line expressions.
- Before adding code, check whether the same behavior already exists elsewhere.
- Avoid duplicate calculations, duplicate validation, and unnecessary abstractions.
- Keep the physics engine independent from the API and frontend.
- Use explicit SI units in variable and field names.
- Add or update tests for every new calculation or decision rule.
- Do not present untested or illustrative numbers as computed mission results.
